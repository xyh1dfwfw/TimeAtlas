# TimeAtlas

TimeAtlas 是一个互动历史网站。它不把历史做成单纯的年份表或百科条目，而是让用户选择一个历史身份，进入那个时代的一天，面对一个关键选择，并把自己的选择放回真实历史背景中理解。

## 当前 MVP

第一版包含 5 个历史身份：

- 唐代长安西市商人
- 北宋汴京茶铺学徒
- 明代江南读书人
- 清末广州十三行买办助手
- 二战伦敦普通居民

每个身份包含：

- 时代、地点、身份卡
- 日常生活切片
- 关键时间线
- 历史岔路口选择
- 短期结果、长期影响、历史反思
- 真实历史对照与后续资料占位

## 技术栈

- Vite
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## 本地开发

```bash
npm install
npm run dev
```
